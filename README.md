# Casa Pino 2027: keuzepagina

Statische pagina (GitHub Pages) + Firebase Firestore voor antwoorden en ideeën.

- Vragen en kostenramingen: `questions.js` (nieuwe vraag = nieuw blok met uniek `id`).
- Namen en posities op de foto: `people.js`. Avatars: `avatars/<id>.svg`.
- Firestore-regels: `firestore.rules` → Firebase console → Firestore → Rules → Publish.
